# Browser-Proxy Documentation

This folder is the working memory of the Browser-Proxy project.

It documents the project vision, roadmap, architecture, Raspberry Pi setup, Android native build setup, native WebView plans, fingerprint engine, proxy engine, database design, API design, UI/UX ideas, release plan, troubleshooting notes, security model, and project history.

When something important is discovered, it should be added here instead of relying on memory.
