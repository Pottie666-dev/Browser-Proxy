# Cloud Browser

## Vision

Launch a real desktop browser in the cloud from Browser-Proxy with one tap.

```text
Phone
  ↓
Browser-Proxy
  ↓
Cloud Session API
  ↓
Browser Container
  ↓
Desktop Chromium
```

## MVP

- One tap to launch a cloud browser
- Automatic secure connection
- Full desktop Chromium
- Mobile-first controls
- Keyboard and mouse support
- Clipboard support
- File upload and download
- Automatic reconnect
- Session persistence
- Per-account browser profile

## Design Goals

- Ready in under 15 seconds
- Low bandwidth
- Mobile-first
- Persistent only when requested
- Easy to deploy
- Isolated per account
- Secure by default
