# UI / UX

## Main Screens

### Account Vault

Purpose: list, search, filter, favorite, tag, edit, delete, and open accounts.

Current features include search, favorites, tags, identity badge, image badge, and quick actions.

### Account Form

Purpose: create/edit account, generate email/username/password, store images, choose timezone, and store wallet/crypto fields.

Future additions: proxy picker, device picker, region picker, identity health preview, and clone account.

### Browser

Current features: address bar, WebView, proxy wrapping, account badge, debug panel, tabs, bookmarks, history, session isolation controls, and native profile diagnostics.

Future additions: downloads panel, upload helper, autofill drawer, proxy status chip, identity health score, fingerprint dashboard, saved notes, quick actions.

## Mobile-First Workflow

The app is being built primarily for phone usage. Design priorities are large touch targets, minimal typing, quick copy/paste, one-tap account switching, clear session reset, clear identity diagnostics, and simple browser controls.
